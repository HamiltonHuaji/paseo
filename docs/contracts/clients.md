# 客户端行为契约

除单独标明的平台范围，功能遵守项目的跨平台与能力门控约定。
位置、布局模式、可到达的操作与状态连续性都是用户可观察的行为，升级后继续满足。
组件拆分和具体实现可以随上游变化。

## CONNECTION-01 — 版本切换保留已配对主机

客户端重启、覆盖安装和升级后，已保存主机的身份、连接地址、配对密钥、
认证信息和用户命名继续可用，不要求重新输入 pairing link。当前版本读取其他版本
保存的数据时，不能因一个未知字段、连接类型或损坏条目删除整份列表。

无法解析的数据保留用于恢复，其余有效主机仍可使用。只有用户明确删除或清除客户端
数据才移除相应记录；当前版本明确删除的主机不会在重启后复活。连接列表保持单一
存储格式，不为绕过已发布旧版本的破坏性读取另存一份兼容格式。

验收：候选读取不同版本的连接记录，覆盖 direct、relay、认证与 Connected Hosts
路由，核对有效连接及未知内容的保留。加入一个未知或损坏条目
后，其余主机仍可读；在候选中删除一个主机后重启，确认删除有效。桌面安装器和运行时
采用稳定的用户数据归属；平台实测与存储逻辑检查分别记录，不互相冒充。

## FILE-01 — 工作区 symlink 资源可用

受信任客户端能列出、读取和预览经 workspace symlink 引用的外部文件，
包括数据集和结果。恶意相对路径遍历和文件打开时的链接替换仍被拒绝；
具体信任边界见 [SECURITY](../../SECURITY.md)。

验收：外部图片和结果 symlink 正常预览，traversal 与末端链接替换场景失败。

## FILE-02 — 文件下载使用当前可达连接

下载跟随当前 host 的有效连接，relay 用户无需访问保存但不可达的 LAN 地址。
只有当前有效的 direct TCP 路径可用于认证 HTTP 下载；其他连接仍能通过现有
host 通道取得文件。Web/native 保存结果与文件名冲突可处理。

验收：仅 relay、切换 direct/relay、过期 LAN 地址和同名文件下载均得到正确文件。

## LINK-01 — 链接目标可检查和复制

有指针的客户端可悬停查看完整目标，将指针移入浮层并选择、复制文本；
操作期间浮层保持打开。普通只读 tooltip 不抢占无关指针操作。

验收：长路径和 Markdown 链接可复制完整目标，离开交互区域后按约定关闭。

## MD-01 — 技术 Markdown 离线可读

Web/Electron 和 Android 的行内及块级公式可离线渲染、复制原始 TeX；
不支持的环境与非法公式保留可读源码。流式公式边界、货币文字、代码块
不会互相误判。常见段落和图片 HTML 内容可读，任意 HTML 不因此获得执行权限。
闭合块公式中的空行、独占一行的等号与加号属于公式，不能变成标题、列表或普通段落。
Web/Electron 的公式点击复制与包含公式的选区复制均保留 TeX 命令、下标和换行，不二次转义；
复制后再渲染仍得到同一公式。

验收：公式流式生成、断开的分隔符、非法表达式、美元金额、代码与有限 HTML
混排保持正确；包含多行链式求导、对齐环境、注释、引用中的公式及复制往返。
更换 Markdown renderer 后仍满足相同行为。

## MD-02 — 问题中的技术内容可读

问题标题和选项说明支持 Markdown、图片和文件链接；资源来自问题所属 host，
文件动作指向正确工作区，不妨碍选择和自由文本回答。

验收：两个 host 的同名图片、公式、代码与文件链接在问题卡片内正确显示和打开，
回答控制保持可用。

## COMPOSER-01 — 多行、发送与排队有稳定按键语义

Enter 换行，Ctrl/Cmd+Enter 执行当前 send/steer，Tab 排队。
停止是显式动作，不由发送快捷键冒充。Web 与原生硬件键盘行为一致，IME 输入安全。

验收：idle/running、输入法组词和多行内容下动作符合界面说明；
idle 不发起仅适用于 running 的操作。

## TABS-01 — 顶部与左侧 tab 导航

### 位置与偏好

在客户端设置中选择“顶部”或“左侧”，默认顶部；选择随客户端重启保留，
从旧 fork 升级后保留已有选择。同一客户端的各工作区采用这个偏好，
每个 pane 根据自身宽度决定实际布局。

左侧模式中，tab 栏位于该 pane 内容左边，与聊天、编辑器或终端横向并列，
占满 pane 可用高度。列表独立纵向滚动，底部动作区始终可到达。
列表增长消耗栏内滚动空间，内容区保持全高。

接近旧版的可观察几何基准：左栏宽 220 逻辑像素、行高 36；宽度至少 640 的
非紧凑 Web/Electron pane 使用左栏。低于该宽度时，该 pane 使用顶部 tabs；
恢复足够宽度后重新采用左栏。窄 pane 的临时布局不改写用户的左侧偏好。
紧凑布局保留 tab switcher，原生非紧凑布局保留顶部 tabs。

### 内容与动作

切换位置、调整 pane 宽度或进入／退出最大化后，当前 tab、编辑器未保存内容、
composer 草稿、终端连接和正在执行的 agent 保持连续。布局切换不会关闭或重新创建
这些内容，也不会将 tab 移到其他 pane。

每个 tab 保留图标、名称、选中状态、运行／待处理／未保存标识、关闭入口与适用菜单。
重名 tab 仍可区分；操作使用实际 tab 身份。关闭 tab 沿用原有关闭／归档语义。
纵向菜单的相邻关闭方向显示为“上方／下方”，横向显示为“左侧／右侧”。
移动到首尾在已处于边界时禁用；紧凑布局菜单也能完成移动到首尾。

左栏底部按平台能力保留 agent、终端、浏览器快速创建、新建 tab、向右／向下分屏入口；
在适用场景保留最大化、还原和退出专注模式。长列表滚动后这些入口仍可用。
创建和分屏作用于入口所属 pane；全局新建快捷键作用于当前焦点 pane。

### 滚动与拖拽

顶部 tabs 在溢出时支持横向触控板、横向滚轮和普通滚轮浏览，并可移动到首尾。
左栏支持独立纵向滚动。选中另一个 tab 时仅滚动到让目标可见的位置；
用户浏览其他条目时，普通运行状态或标题更新不会将列表反复拉回当前 tab。

两种布局的 tab 都能在 pane 内重排，并沿用工作区跨 pane 移动与拖出分屏能力。
拖动预览、插入位置和最终 tab 归属一致，左右布局的移动方向可辨认；
不能因只迁入栏内排序而失去跨 pane 拖放。树中折叠导致的排序限制见 TABS-02。

### 验收结果

| 场景                                                         | 完成后应看到的结果                                             |
| ------------------------------------------------------------ | -------------------------------------------------------------- |
| 设置左侧、刷新、重新打开客户端                               | 左侧偏好保留；已有旧版左侧偏好仍生效                           |
| 同一工作区含宽、窄两个 pane                                  | 宽 pane 是左栏，窄 pane 是顶部；两边各自选择和内容正确         |
| 在 640 宽度上下调整，反复切换顶部／左侧                      | 布局按 pane 恢复；草稿、未保存文件、终端及选中对象保留         |
| 大量 tabs，用户滚动远离当前项，再发生 agent 更新             | 能浏览到首尾；后台更新不抢回滚动位置；主动切换目标后才显示目标 |
| 创建 agent/终端/浏览器、新 tab、向右／向下分屏、最大化／还原 | 控件可到达，动作落在正确 pane，内容持续存在                    |
| 纵横布局之间拖动、pane 内重排、拖出分屏                      | 预览和最终顺序、归属一致；没有复制、丢失或串用 tab             |
| Web/Electron、紧凑浏览器与原生支持范围                       | 各自采用约定布局；未实际验证的平台在版本记录中明确保留         |

## TABS-02 — 左栏中的层级 tab 树

### 分组与显示

已加载名称的 agent 和 terminal，在至少两个 tab 共享 slash 路径前缀时分组；file 及其他 tab 保留自身名称和
动作语义，不因文件路径包含 slash 被误分成 agent 组。多级分组支持缩进、折叠和展开，
只有一个子分组的连续路径压缩显示。分组显示名称、后代数量和展开方向；
叶子省略已经由祖先表达的前缀。

例如 `research/train/a`、`research/train/b`、`research/eval/a`、`research/eval/b`
在 `research` 下分成 `train` 和 `eval`，两个名为 `a` 的叶子仍操作各自 tab。
若只有一个 `research/eval/a`，它显示为 `research` 下的 `eval/a` 叶子，不生成单例分组。
非相邻 tab 的同前缀归组规则确定；重复完整名称仍是独立叶子。
分组身份随其路径稳定，不由临时行号或当前标题排位决定。

### 选择与折叠

折叠包含当前 tab 的组后，组仍显示其中有选中项，内容区继续显示原 tab。
用户选择另一个隐藏叶子时，其祖先展开并把目标滚动到可见位置。
普通标题、状态刷新不擅自打开用户刚折叠的当前组，也不清空其他组的折叠状态。
重命名导致路径变化或关闭叶子后，分组、计数与选择同步反映实际 tab。

### 排序与操作

展开的叶子保留关闭、重命名、适用复制动作、reload、heartbeat 和 pane 操作，
动作不被分组行截获。完整展开时拖拽叶子能重排、移动到其他 pane 或分屏。
有折叠组时，不能确认完整底层顺序的拖拽被禁用；不得用仅可见的行静默重排隐藏 tab。
分组行本身不冒充一个可拖拽的 tab。显式的叶子“移到首尾”仍作用于完整 tab 序列。

验收：使用上述嵌套名称、同名叶子、重复完整名称及混合 file/terminal tabs，
检查折叠当前组后的选中标识、切换隐藏叶子的展开与定位、重命名／关闭后的组变化、
所有菜单动作的真实目标，以及完整展开和存在折叠组两种情况下的拖拽结果。

## VSCODE-01 — 已退役的 VS Code 扩展

用户于 2026-10-22 明确要求移除 VS Code 扩展并停止开发。
新版产品不包含该扩展的 workspace、源码、专用嵌入入口、构建脚本或发布任务。
保留本编号用于追溯退役决定；VS Code 集成不再属于迁移后的产品能力。

验收：安装包、构建与发布入口不再生成 VSIX，不再要求扩展专属依赖。
普通文件打开到用户选择的编辑器不属于被退役的扩展。

## AUTO-01 — 会话内可编辑 heartbeat

会话菜单按需提供 heartbeat 编辑，覆盖 prompt、名称、every、cron、maxRuns、
expiresAt 和时区。合法 cron 字段组合可表达，不限于少量预设。
无改动不产生更新，非法输入能定位；清空时区的结果明确为 UTC。

验收：打开后取消、无改动保存、组合 cron、清空时区和过期次数设置均有正确结果，
既有 heartbeat 不因编辑表单而意外改变。

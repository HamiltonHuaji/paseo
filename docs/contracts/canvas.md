# Canvas 可读性契约

会话、v1 Experiments 和 Works v2 使用同一套空间阅读标准。用户需要找到一个工作、
看懂它从哪里来、比较分支，并在回来时找回刚才的位置。本契约规定这些任务的结果；
具体方向、排列算法、曲线形式和像素间距由候选方案决定。

## CANVAS-01 — 关系可以直接读懂

每条关系能辨认来源与目标。共享来源的分支不会因摆放顺序被误读为串行继承；
互不关联的工作不会因连线重合看起来属于同一条链。独立关系群有可辨认的空间边界。

追踪一条边时，箭头与终点卡片匹配，分叉处仍能分辨去向。转折不会贴住另一张卡的
边框，卡片正文不被线遮挡。存在空闲通道时，路线绕开第三方卡片；拖动与调整大小后
连接点跟随真实边界。显示过滤不能留下指向隐藏卡片的悬空边。

验收包含一个来源的多分支、多代继承、独立工作混排、不同卡片尺寸、长链和人工放置
的障碍物。对比关系是否容易追踪，不能只检查边的数量。

## CANVAS-02 — 空间服务于阅读

正常文字大小下，用户能在相近位置比较相关卡片。重排不产生卡片重叠，不为少量工作
留出大片无用空白，也不为了装进固定宽度而把复杂关系压成难以追踪的一条蛇形队列。
长链可以折返，分支可以展开；方向变化不能让来源关系产生歧义。

密集图的评价同时包括完整概览与局部阅读。更小的外接矩形不自动意味着更好；
应记录必须缩小到什么程度才能概览、追踪一条长关系需要移动多远、分支是否仍可比较。
不要求每张图使用相同方向，也不要求一轮迭代找到全局最优解。

验收使用真实积累的图，保留前后对照和不利案例。区分画布 Card 数量与详情中的
Item / Attempt 数量；大量详情记录不能冒充密集关系图。

## CANVAS-03 — 空间变化可预测

相同输入的重排结果一致；数据返回顺序和状态刷新不会随机打乱位置。
手动位置和尺寸属于用户数据。数据更新、新卡片、筛选和断线恢复不擅自重排已有
手工布局。显式重排的影响可预期，撤销和持久化遵守各 surface 的操作契约。

按时间查看时，界面所声明的事件与排序方向必须与结果相符；没有事件的记录可辨认，
长时间空档不需要按时长制造空间。时间排列与关系排列可以采用不同空间策略。

验收包含输入乱序、新增、删除、重命名、状态刷新、缺失来源和循环引用。
缺失或错误关系不导致挂起，也不伪造一个不存在的来源。

## CANVAS-04 — 交互仍然直接

用户能在概览与局部阅读之间缩放。普通滚轮平移，Ctrl＋滚轮围绕指针所在位置缩放，
不会同时滚动画布或缩放整页。无需知道快捷键，也能通过固定大小的可见控件放大、
缩小、查看与选择比例、恢复 100%、适应全部可见卡片及聚焦选中项。
键盘快捷键只在画布操作范围内生效，不抢占正文输入。

卡片、文字、关系线与网格使用一致的空间比例；拖动与调整大小跟随指针，持久化的
位置和尺寸不因缩放本身变化。缩放不丢失选择，数据刷新与保留页面切换不重置视角。
适应全部尊重筛选结果，空画布和没有选中项时不执行无目标的聚焦操作。

平移、缩放、选卡、拖动和调整大小能连续响应。单纯移动相机不重新计算关系路径；
路由耗时随可见图的复杂度增长，而不是随世界坐标的数值大小增长。
新算法不能用重置相机或丢失选择来掩盖布局问题。

验收记录实际图规模和操作结果，包含鼠标锚点、普通滚轮、触控板捏合、可见控件、
缩放后的拖动与调整尺寸、关系端点、筛选、空图和窄屏。浏览器通过不代表原生设备已验证。

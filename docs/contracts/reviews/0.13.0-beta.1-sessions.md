## 迁移归属

旧 fork 的 `9f1469b3f`、`543632c77`、`d70a8433e` 原生分叉与边界能力迁移；
`4a908baee` 显式导入副本迁移；`1bd70fb50` 中 Canvas、稳定来源、回复时间投影迁移。
这些路径按上游新的 launch context、动态 tier、协议 capability 和 workspace 结构适配。
旧代码的固定 fast-model 白名单、旧 provider 配置覆盖和旧工作区页面不回放。
本模块未修改 Works/Experiments 的功能实现，也未采用已废弃的会话/状态存储设计。

上游 LF 解码、现代 rewind、单写者关闭顺序、异步问题和增量 placement 逻辑复用。
补充改动覆盖模型分页、有限日志、终态映射、根工具收尾、原生身份别名与 rewind
失败恢复。新增 wire 字段均可选；新能力以 server feature 门控。现有 RPC 没有重命名。

## 整合后的查看入口

- 公式：任意 agent 消息包含 `$a^2+b^2=c^2$`、`$$\int_0^1 x\,dx$$` 或 `\(a+b\)`；Web 公式元素为 `[role="math"]`，点击复制 TeX。继续检查 `$5 and $10`、代码块与未闭合分隔符。
- Heartbeat：右键 agent tab → Heartbeats；紧凑界面 tab switcher 的会话菜单也有该项。浮层 `agent-heartbeats-sheet`，编辑按钮 `heartbeat-edit-<scheduleId>`，保存 `heartbeat-save`，输入 `heartbeat-prompt`。
- 纵向 tabs：顶部 tab rail 的“Vertical tabs”按钮切换；列表 `workspace-vertical-tabs`，普通横向列表 `workspace-tabs-scroll`。将多个 agent 命名为 `research/train/a`、`research/train/b`、`research/eval/a` 查看树。
- 链接：悬停任意 Markdown 链接，移入浮层并选择完整目标。
- 问题卡片：由 agent 发出包含公式、代码、文件图片的交互问题，验证选项选择和自由文本回答。

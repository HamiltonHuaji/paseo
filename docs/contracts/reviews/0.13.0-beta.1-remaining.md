## 执行状态补修

CODEX-03 的历史 started/interacted 现在携带 `executionStatus: unknown`；明确的
interrupted 仍为 canceled。该标记贯通 provider descriptor、client store、工具、track
和详情 pane；当前客户端显示未知，不显示运行或成功标记，不自动归入 finished。
实际 child started/completed 事件清除未知标记，父 turn 完成不替 child 下结论。

协议用可选字段保留旧 status 枚举，旧客户端仍可解析，但仍使用旧显示语义；没有宣称
它们获得未知状态表达。源码与定向状态转换已核对，真实 child、断线重连和原生 UI
的完整运行矩阵仍未验收。
